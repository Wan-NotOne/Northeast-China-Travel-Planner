# ❄️ Northeast China Travel Planner

A local-first travel planning web app for an 18-person, 9-day / 8-night Northeast China trip (22 February–2 March 2027).

**Main route:** Harbin → Yichun → Heihe  
**Alternative:** Hulunbuir

## Features
- Trip overview and pre-departure checklist
- Nine-day itinerary editor
- Attraction shortlist and planning status
- Hotel and accessibility notes
- CNY budget tracker
- Winter-weather and border-crossing backup plans
- JSON import/export for local backups

## Getting started
Open `index.html` in a modern browser. No installation or paid hosting required.

## Privacy
Entries are stored only in your browser using `localStorage`. They are not synchronized across devices or uploaded to GitHub. Export JSON regularly for backups, and do not commit personal traveller details to this public repository.

## Important
Accessibility, transport, weather, attraction opening dates, and Russia border-entry requirements are **not verified**. Confirm with providers and official authorities before booking.

## GitHub Pages
This is a static site suitable for GitHub Pages. To publish, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
